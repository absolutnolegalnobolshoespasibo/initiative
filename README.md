# Боевая инициатива — расширение для Owlbear Rodeo

Расширение добавляет в Owlbear Rodeo трекер инициативы для боя:
индивидуальная "изначальная инициатива" для каждого персонажа, бонус за
быструю готовность (чем дольше тянешь — тем меньше бонус), сортировка по
инициативе с учётом очерёдности готовности, звук начала раунда и
автоматическое центрирование камеры по очереди боя.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест расширения — говорит Owlbear Rodeo, как его загрузить. |
| `index.html` | HTML-страница попап-окна (открывается по иконке слева). |
| `style.css` | Оформление (тёмная тема, в стиле интерфейса Owlbear Rodeo). |
| `main.bundle.js` | Собранный файл: SDK + вся логика в одном месте. Именно его подключает `index.html`. |
| `battebeginsound.mp3` | Звук, который играет при начале раунда. |
| `icon.svg` | Иконка действия (кубик) в левой панели. |
| `main.js` | Исходник: связь с Owlbear Rodeo SDK, синхронизация состояния, отрисовка. |
| `logic.js` | Исходник: правила расчёта инициативы и порядка боя — без SDK и DOM. |
| `logic.test.mjs` | Необязательные тесты для `logic.js` (см. раздел "Тесты" в конце). |

**На хостинг нужно выложить 6 файлов:** `manifest.json`, `index.html`,
`style.css`, `main.bundle.js`, `battebeginsound.mp3`, `icon.svg`.

`main.js`, `logic.js` и `logic.test.mjs` — это исходники, из которых
собирается `main.bundle.js`. В браузере они не используются; выкладывать
их на хостинг не обязательно (но и не вредно). Если захочешь разобраться
или поменять правила боя — начни с `logic.js`, там нет ничего, кроме
математики и сортировки, с комментариями на русском. **Важно:** после
правки `main.js` или `logic.js` нужно пересобрать `main.bundle.js` — см.
раздел "Сборка".

## Как реализованы правила

1. **Подготовка.** В попапе — список всех токенов слоя `Character` в
   порядке их добавления на сцену (по z-индексу токена), с полем
   "Изначальная инициатива" (целое число, по умолчанию 0). Кнопка
   "Начать раунд" видна всем, но активна только у мастера.

2. **Начать раунд.** Запускается отсчёт времени раунда и играет звук
   `battebeginsound.mp3` — у мастера и у всех игроков, у кого открыт
   попап расширения. Кнопка "Начать раунд" превращается в "В бой",
   которая неактивна, пока не готовы все.

   Сам отсчёт времени на экране не показывается — он работает "внутри"
   и нужен для расчёта бонуса (см. следующий пункт).

3. **Готовность.** У каждого персонажа появляется галочка. Кто нажал её
   сразу — получает полный бонус **+10** к инициативе; за каждые 30
   секунд промедления после начала раунда бонус меньше на 1 (ниже нуля
   не опускается). Бонус фиксируется в момент нажатия и дальше не тает.
   Повторное нажатие снимает галочку и убирает бонус.

   Значения `ROUND_BONUS = 10` и `DECAY_INTERVAL_MS = 30000` — в начале
   `logic.js`, их легко поменять.

   - **Игроки** видят только персонажей из категории "доступны
     игрокам" (PC).
   - **Мастер** видит сначала персонажей "недоступных игрокам" (NPC),
     затем "доступных игрокам" (PC).

   *Как определяется PC/NPC:* по умолчанию токен, созданный мастером,
   считается NPC, а созданный игроком — PC. В фазе подготовки мастер
   может вручную переключить метку **PC/NPC** у любого токена кнопкой
   рядом с полем инициативы — это сохраняется и используется дальше.

4. **В бой.** Когда все подтвердили готовность, мастер может нажать "В
   бой". Персонажи сортируются по итоговой инициативе (по убыванию);
   при равенстве выше тот, кто поставил готовность раньше. Кнопка
   становится "Следующее существо", камера центрируется на первом в
   списке.

5. **Следующее существо.** Каждое нажатие центрирует камеру на
   следующем персонаже списка. После последнего — кнопка превращается
   в "Начать раунд", всё готово для нового раунда (изначальные
   инициативы сохраняются, бонусы и готовность сбрасываются).

Дополнительно: в фазах "Раунд" и "Бой" у мастера есть маленькая ссылка
**"Сбросить раунд / Сбросить бой"** — на случай ошибки, чтобы вернуться
к подготовке без необходимости проходить весь цикл.

## Про звук

- Звук слышат все, у кого в этот момент **открыт попап расширения**.
  Если игрок его закрыл — он ничего не услышит.
- Браузеры не разрешают проигрывать звук, пока пользователь не кликнул
  внутри страницы. Расширение обходит это: при первом же клике внутри
  попапа звук один раз "прокручивается" беззвучно, и дальше всё играет
  нормально. На практике это значит, что самый первый раунд после
  открытия попапа игрок может не услышать, если вообще ещё ничего не
  нажимал.
- Громкость меняется константой `BATTLE_SOUND_VOLUME` в начале
  `main.js` (от 0 до 1). Чтобы поставить другой звук — положи свой файл
  рядом и поменяй `BATTLE_SOUND_URL`. После правки — пересобрать бандл.

## Установка

Owlbear Rodeo загружает расширения по публичной ссылке на
`manifest.json`, поэтому файлы нужно куда-то выложить. Проще и
бесплатнее всего — **GitHub Pages**.

### Шаг 1. Выложить файлы на GitHub Pages

1. Зайди на [github.com](https://github.com) и создай аккаунт, если
   его ещё нет.
2. Нажми **New repository**. Дай имя, например
   `owlbear-initiative-tracker`, выбери **Public**, создай репозиторий.
3. На странице репозитория нажми **Add file → Upload files** и
   перетащи туда файлы (`manifest.json`, `index.html`, `style.css`,
   `main.bundle.js`, `battebeginsound.mp3`, `icon.svg`) — именно в
   корень репозитория, не в подпапку. Нажми **Commit changes**.
4. Перейди в **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Source: Deploy from a
   branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
6. Подожди минуту-две — GitHub покажет адрес вида
   `https://<твой-логин>.github.io/owlbear-initiative-tracker/`.
7. Ссылка на манифест будет:
   `https://<твой-логин>.github.io/owlbear-initiative-tracker/manifest.json`
   Открой её в браузере — должен показаться текст манифеста (JSON), а
   не ошибка 404.

> Если файлы уже лежали на хостинге раньше — просто загрузи новые
> версии поверх старых. После обновления в Owlbear Rodeo обнови
> страницу комнаты (Ctrl+F5), чтобы браузер не показал старую версию из
> кэша.

### Шаг 2. Добавить расширение в Owlbear Rodeo

1. Открой [owlbear.rodeo](https://www.owlbear.rodeo) и зайди в свой
   аккаунт.
2. В меню профиля найди пункт **Add Extension** (Добавить
   расширение).
3. Вставь ссылку на `manifest.json` из шага 1 и подтверди.

### Шаг 3. Включить расширение в комнате

1. Открой (или создай) комнату.
2. Внизу слева открой меню **"..."** и выбери **Extensions**.
3. Включи **«Боевая инициатива»**.
4. В левой панели появится иконка-кубик — это и есть трекер
   инициативы. Открой её попап и начинай работу.

> ⚠️ Расширения видны и работают у всех, кто заходит в комнату.
> Игрокам стоит один раз сообщить, что в комнате включено стороннее
> расширение (это стандартная практика для Owlbear Rodeo).

## Сборка

`main.bundle.js` собирается из `main.js` + `logic.js` + SDK Owlbear
Rodeo. Нужен [Node.js](https://nodejs.org). В папке с файлами:

```bash
npm install esbuild @owlbear-rodeo/sdk@3.1.0
npx esbuild main.js --bundle --format=esm --target=es2020 --outfile=main.bundle.js
```

Пока `main.js` и `logic.js` не менялись, пересобирать ничего не нужно —
готовый `main.bundle.js` уже лежит рядом.

## Настройка

Все "числа правил" собраны в начале `logic.js`:

```js
export const ROUND_BONUS = 10;           // максимальный бонус за готовность
export const DECAY_INTERVAL_MS = 30_000; // за этот интервал промедления бонус -1
```

Звук настраивается в начале `main.js` (`BATTLE_SOUND_URL`,
`BATTLE_SOUND_VOLUME`).

Цвета и размеры — в начале `style.css`, в блоке `:root` (переменные
`--accent`, `--bg`, `--ready` и т. д.).

## Технические детали

- Состояние раунда/боя хранится в **метаданных комнаты** (видно всем,
  синхронизируется автоматически Owlbear Rodeo).
- "Изначальная инициатива" и метка PC/NPC хранятся в **метаданных
  каждого токена** — то есть остаются с персонажем между раундами и
  сценами.
- Персонажи — это токены на слое **Character** (`layer === "CHARACTER"`,
  `type === "IMAGE"`). Если токен не на этом слое, расширение его не
  увидит.
- Интерфейс перерисовывается только тогда, когда разметка реально
  изменилась, а позиция прокрутки и фокус в поле ввода при этом
  сохраняются — поэтому список больше не "прыгает" наверх.

## Тесты (необязательно)

`logic.js` — это чистые функции без SDK и DOM, поэтому правила боя
(бонус за готовность, сортировка, переход между фазами) проверены
автоматическими тестами в `logic.test.mjs`. Чтобы запустить их, нужен
установленный [Node.js](https://nodejs.org) — затем в папке с файлами:

```bash
node --test
```

Все 22 проверки должны пройти (`pass 22`, `fail 0`). Для самого
расширения это не требуется — просто способ убедиться, что правила
считаются так, как описано выше, и безопасно менять константы
(`ROUND_BONUS`, `DECAY_INTERVAL_MS`) при необходимости.
